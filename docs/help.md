# Help and frequently asked questions

Find an answer by topic. Open a question to see its answer.

<section class="xn-faq-section" id="access" data-faq-section data-expand-label="Expand all" data-collapse-label="Collapse all" aria-labelledby="access-title" markdown="1">

<div class="xn-faq-section__heading"><h2 id="access-title">Access and community</h2></div>

<div class="xn-faq-items" id="access-questions" markdown="1">

<details class="xn-faq-question" markdown="1">
<summary>How can I access X-Nite?</summary>
<div class="xn-faq-answer" markdown="1">

Support the project on [Buy Me a Coffee](https://buymeacoffee.com/xnite) to receive access to our Discord community. There you will find X-Nite downloads, updates and a place to chat with other users.

</div>
</details>

<details class="xn-faq-question" markdown="1">
<summary>Do I need to pay monthly?</summary>
<div class="xn-faq-answer" markdown="1">

No. Support is a **one-time contribution, with an amount of your choice**. Your contribution helps make maintenance and new features possible, both of which require time and dedication.

</div>
</details>

<details class="xn-faq-question" markdown="1">
<summary>Where can I find downloads and updates?</summary>
<div class="xn-faq-answer" markdown="1">

Links are available in the designated Discord channels. This website provides feature previews, the installation guide and frequently asked questions.

</div>
</details>

<details class="xn-faq-question" markdown="1">
<summary>Do I need experience with Playnite to use X-Nite?</summary>
<div class="xn-faq-answer" markdown="1">

No prior experience is required. Our illustrated guide takes you from installing Playnite to creating your first X-Nite profile.

</div>
</details>

<details class="xn-faq-question" markdown="1">
<summary>Can I suggest improvements or report problems?</summary>
<div class="xn-faq-answer" markdown="1">

Yes! Use the Discord community channels to share suggestions and report problems. When reporting an issue, include the steps to reproduce it and, if possible, a screenshot or video.

</div>
</details>

</div>

</section>

<section class="xn-faq-section" id="performance" data-faq-section data-expand-label="Expand all" data-collapse-label="Collapse all" aria-labelledby="performance-title" markdown="1">
<div class="xn-faq-section__heading"><h2 id="performance-title">Performance</h2></div>
<div class="xn-faq-items" id="performance-questions" markdown="1">

<details class="xn-faq-question" markdown="1">
<summary>How can I keep navigation smooth?</summary>
<div class="xn-faq-answer" markdown="1">

Keep Playnite, graphics drivers and integrations updated. Avoid imported images far larger than your display resolution, and reduce visual effects when the option is available.

</div>
</details>

<details class="xn-faq-question" markdown="1">
<summary>Why should I wait for the first load before comparing performance?</summary>
<div class="xn-faq-answer" markdown="1">

The first load can include covers and achievement data. Allow it to finish before comparing navigation. If the issue persists, include your resolution, GPU, library size and test time in your report.

</div>
</details>

<details class="xn-faq-question" markdown="1">
<summary>Should I delete extension data to fix slowness?</summary>
<div class="xn-faq-answer" markdown="1">

No. The extension data directory contains your profiles and their settings. Do not delete it as a performance fix.

</div>
</details>

</div>
</section>

<section class="xn-faq-section" id="troubleshooting" data-faq-section data-expand-label="Expand all" data-collapse-label="Collapse all" aria-labelledby="troubleshooting-title" markdown="1">
<div class="xn-faq-section__heading"><h2 id="troubleshooting-title">Troubleshooting</h2></div>
<div class="xn-faq-items" id="troubleshooting-questions" markdown="1">

<details class="xn-faq-question" markdown="1">
<summary>Why does X-Nite not appear in the theme list?</summary>
<div class="xn-faq-answer" markdown="1">

Confirm that the `.pthm` package was installed, restart Playnite and select X-Nite as the **Fullscreen** theme. Review the [installation guide](installation/01-download-playnite.md) if needed.

</div>
</details>

<details class="xn-faq-question" markdown="1">
<summary>What should I do if a profile or its images disappear?</summary>
<div class="xn-faq-answer" markdown="1">

Do not reinstall by removing data or change `ExtensionsData` before investigating. Report the previous and currently installed versions so the issue can be checked.

</div>
</details>

<details class="xn-faq-question" markdown="1">
<summary>Why does the desktop appear when I launch a game?</summary>
<div class="xn-faq-answer" markdown="1">

Disable **Minimize after starting a game** in Playnite Fullscreen settings.

</div>
</details>

<details class="xn-faq-question" markdown="1">
<summary>What if a game opens behind Playnite?</summary>
<div class="xn-faq-answer" markdown="1">

Report the game name, launcher, whether anti-cheat is used and whether the game audio starts. Include logs from the same time, removing personal data before sharing.

</div>
</details>

<details class="xn-faq-question" markdown="1">
<summary>What information should a useful issue report include?</summary>
<div class="xn-faq-answer" markdown="1">

Include the Playnite and X-Nite versions, Windows version, resolution, controller used, exact reproduction steps and relevant logs. For performance issues, also include GPU, library size and the time of the test.

</div>
</details>

</div>
</section>
