# Logros
El Hub muestra progreso, logros bloqueados y desbloqueados, rareza, Collection Score y Prestige Score cuando las integraciones ofrecen esos datos.

Abre el Hub, entra en un perfil, selecciona Juegos y elige un título. Las notificaciones siguen el idioma y el color del perfil activo.
