# First setup

## Integrations

1. Review the recommended integrations on the one-time setup screen.
2. Select any item marked **Install now** and confirm **Install add-on?** in Playnite.
3. Restart Playnite when requested.
4. Complete authentication or provider settings from the Desktop add-ons menu when required.
5. Select **Continue**. You can revisit the list at `Settings > Extensions > Integrations`.

The integration screen is not shown again after you continue. A new installation opens the profile selector in English by default.

## First profile

1. Select **Add** on the **Who is playing today?** screen.
2. Choose the profile language.
3. Enter the displayed profile name.
4. Choose an avatar or import a photo.
5. Select an accent color.
6. Choose or import the main background.
7. Review the license and finish setup.

Each profile keeps its own language, appearance, favorites, groups and pinned games.
