# Profils
Chaque profil conserve son nom, avatar, couleur, fonds, favoris, groupes, jeux récents, jeux épinglés et préférences du Hub.

<img src="../../assets/screenshots/profiles.webp" alt="Sélecteur avec plusieurs profils">

<img src="../../assets/screenshots/profile-customization.webp" alt="Personnalisation du profil avec avatar, couleur et arrière-plans">

Ouvrez le Hub, entrez dans votre profil et sélectionnez Personnalisation. Utilisez X pour modifier un élément importé lorsque Modifier apparaît.
