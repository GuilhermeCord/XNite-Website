## Componentes principais

Instale os dois componentes: **X-Nite Profile System (.pext)** e **tema Fullscreen X-Nite (.pthm)**. Adicione o Playnite Achievements para conquistas e Gamescore. Logos, downloads de trailers e músicas dos jogos dependem das respectivas integrações opcionais.

!!! info "Steam & Audio"
    Amigos e presença da Steam usam o cliente Steam conectado. Dispositivos de saída, volume do sistema e áudio dos jogos usam os controles nativos do X-Nite. Não é necessária uma extensão separada de amigos ou de áudio.
