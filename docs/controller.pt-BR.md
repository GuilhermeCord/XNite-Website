# Controle e navegação

| Comando | Ação comum |
|---|---|
| A / Enter | selecionar ou confirmar |
| B / Esc | voltar ou cancelar |
| Direcional | mover o foco |
| LB / RB | alternar guias do Hub |
| X | editar o item selecionado quando a legenda Editar estiver visível |

O botão B retorna primeiro da camada atual. Por exemplo, ele fecha um editor antes de fechar a tela que abriu esse editor.
