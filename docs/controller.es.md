# Control y navegación
| Entrada | Acción |
|---|---|
| A / Enter | Seleccionar o confirmar |
| B / Esc | Volver o cancelar |
| Cruceta | Mover el foco |
| LB / RB | Cambiar pestañas del Hub |
| X | Editar el elemento importado seleccionado |

B cierra primero la capa actual, como un editor abierto desde el perfil.
