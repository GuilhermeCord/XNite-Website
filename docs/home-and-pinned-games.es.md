# Inicio y juegos fijados
Para fijar un juego, abre sus detalles, entra en Más opciones y elige `Fijar en Inicio`.

<img src="../../assets/screenshots/game-details.webp" alt="Detalles del juego con arte, tráiler y acciones principales">

Para reorganizar, pulsa Izquierda desde el primer juego, abre Organizar, selecciona un juego y muévelo con Izquierda o Derecha. Confirma para guardar o pulsa B para cancelar.
