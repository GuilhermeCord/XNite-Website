<section class="xn-feature-section" data-feature-section="all"><h1>Toute votre bibliothèque, réunie</h1><p>Parcourez Tous les jeux et sélectionnez une jaquette pour voir les actions. Ouvrez Détails pour découvrir le jeu ou Plus d’options pour le gérer. Les contrôles supérieurs permettent de changer le tri.</p><div class="xn-feature-gallery" data-feature-gallery aria-label="Toute votre bibliothèque, réunie."><figure data-feature-frame><a href="../../assets/features/library/01.webp" data-guide-image data-close-label="Fermer l’image" aria-label="Agrandir l’image: Tous les jeux"><img src="../../assets/features/library/01.webp" alt="Tous les jeux" width="1920" height="1080" loading="lazy" decoding="async"></a><figcaption>Tous les jeux</figcaption></figure></div></section>

<section class="xn-feature-section" data-feature-section="search"><h1>Trouvez votre prochain jeu</h1><p>Ouvrez Rechercher, saisissez une partie du titre et confirmez. La grille affiche les résultats ; effacez la recherche pour retrouver la liste complète.</p><div class="xn-feature-gallery" data-feature-gallery aria-label="Trouvez votre prochain jeu."><figure data-feature-frame><a href="../../assets/features/library/02.webp" data-guide-image data-close-label="Fermer l’image" aria-label="Agrandir l’image: Rechercher"><img src="../../assets/features/library/02.webp" alt="Rechercher" width="1920" height="1080" loading="lazy" decoding="async"></a><figcaption>Rechercher</figcaption></figure><figure data-feature-frame><a href="../../assets/features/library/03.webp" data-guide-image data-close-label="Fermer l’image" aria-label="Agrandir l’image: Résultats filtrés"><img src="../../assets/features/library/03.webp" alt="Résultats filtrés" width="1920" height="1080" loading="lazy" decoding="async"></a><figcaption>Résultats filtrés</figcaption></figure></div></section>

<section class="xn-feature-section" data-feature-section="create"><h1>Nommez votre collection</h1><p>Ouvrez Groupes, choisissez Créer un groupe et saisissez un nom. Rassemblez les jeux par genre, série ou selon vos prochaines envies.</p><div class="xn-feature-gallery" data-feature-gallery aria-label="Nommez votre collection."><figure data-feature-frame><a href="../../assets/features/library/04.webp" data-guide-image data-close-label="Fermer l’image" aria-label="Agrandir l’image: Groupes"><img src="../../assets/features/library/04.webp" alt="Groupes" width="1920" height="1080" loading="lazy" decoding="async"></a><figcaption>Groupes</figcaption></figure><figure data-feature-frame><a href="../../assets/features/library/05.webp" data-guide-image data-close-label="Fermer l’image" aria-label="Agrandir l’image: Nom du groupe"><img src="../../assets/features/library/05.webp" alt="Nom du groupe" width="1920" height="1080" loading="lazy" decoding="async"></a><figcaption>Nom du groupe</figcaption></figure></div></section>

<section class="xn-feature-section" data-feature-section="edit"><h1>Choisissez les jeux du groupe</h1><p>Cochez les jeux souhaités. Vérifiez les éléments sélectionnés, puis choisissez Enregistrer pour appliquer ajouts et retraits. Annuler conserve le groupe enregistré.</p><div class="xn-feature-gallery" data-feature-gallery aria-label="Choisissez les jeux du groupe."><figure data-feature-frame><a href="../../assets/features/library/06.webp" data-guide-image data-close-label="Fermer l’image" aria-label="Agrandir l’image: Choisir les jeux"><img src="../../assets/features/library/06.webp" alt="Choisir les jeux" width="1920" height="1080" loading="lazy" decoding="async"></a><figcaption>Choisir les jeux</figcaption></figure><figure data-feature-frame><a href="../../assets/features/library/07.webp" data-guide-image data-close-label="Fermer l’image" aria-label="Agrandir l’image: Vérifier la sélection"><img src="../../assets/features/library/07.webp" alt="Vérifier la sélection" width="1920" height="1080" loading="lazy" decoding="async"></a><figcaption>Vérifier la sélection</figcaption></figure><figure data-feature-frame><a href="../../assets/features/library/08.webp" data-guide-image data-close-label="Fermer l’image" aria-label="Agrandir l’image: Groupe enregistré"><img src="../../assets/features/library/08.webp" alt="Groupe enregistré" width="1920" height="1080" loading="lazy" decoding="async"></a><figcaption>Groupe enregistré</figcaption></figure></div></section>

<section class="xn-feature-section" data-feature-section="pin"><h1>Ajoutez un groupe à l’accueil</h1><p>Utilisez l’icône de maison près du nombre de jeux pour épingler ou détacher le groupe.
