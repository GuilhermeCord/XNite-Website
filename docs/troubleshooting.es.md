# Problemas comunes
## El tema no aparece
Reinicia Playnite y selecciona X-Nite como tema Fullscreen.

## El escritorio aparece al iniciar un juego
Desactiva `Minimizar después de iniciar un juego` en Playnite Fullscreen.

Incluye versiones, Windows, resolución, control y pasos exactos en cada informe.
