# Manette et navigation
| Entrée | Action |
|---|---|
| A / Entrée | Sélectionner ou confirmer |
| B / Échap | Revenir ou annuler |
| Croix directionnelle | Déplacer le focus |
| LB / RB | Changer d'onglet du Hub |
| X | Modifier l'élément importé sélectionné |

B ferme d'abord la couche active, comme un éditeur ouvert depuis le profil.
