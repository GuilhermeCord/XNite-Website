## Componentes principales

Instala **X-Nite Profile System (.pext)** y el **tema Fullscreen X-Nite (.pthm)**. Añade Playnite Achievements para logros y Gamescore. Logos, trailers y música requieren sus integraciones opcionales.

!!! info "Steam & Audio"
    Amigos y presencia usan el cliente Steam conectado. Salidas de audio, volumen del sistema y audio de juegos usan los controles nativos X-Nite. No necesitas extensiones separadas de amigos o audio.
