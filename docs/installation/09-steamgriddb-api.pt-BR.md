# Criar e aplicar a chave SteamGridDB

<span class="xn-guide-optional">Opcional</span>

1. Abra as [preferências de API do SteamGridDB](https://www.steamgriddb.com/profile/preferences/api) e clique em **Login via Steam**.
2. Depois do login, abra **API** e use **Create API Key**, caso ainda não tenha uma chave.
3. Copie a chave e cole em **SteamGridDB API Key**, dentro de `Extra Metadata Loader > Logos settings`.
4. Se o **SteamGridDB Metadata Provider** também solicitar uma chave, cole a mesma chave nele e salve.

Esta chave é do **SteamGridDB**, não da API Web da Steam. Não é necessário criar uma chave diferente para cada extensão. Sua chave deve permanecer privada; nos prints ela já está ocultada.
