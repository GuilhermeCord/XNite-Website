# Activer les logos des jeux

<span class="xn-guide-optional">Facultatif</span>

Ouvrez `Extra Metadata Loader > Logos settings`. Activez **Enable logos** et vérifiez taille et alignement. **Get API Key** ouvre SteamGridDB ; l’étape suivante explique comment obtenir la clé. Les téléchargements automatiques de logos sont facultatifs.
