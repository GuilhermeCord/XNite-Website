# Instalar las integraciones

En `Menu > Add-ons (F9) > Browse`, instala **Playnite Achievements** para logros y Gamescore. **Extra Metadata Loader** y **Fullscreen Mode Helper** permiten logos y vídeos; **UniPlaySong** es opcional. Elige los proveedores de tus tiendas y SteamGridDB para imágenes. No necesitas todos los proveedores mostrados. Reinicia cuando se solicite. Amigos y audio son nativos de X-Nite.
