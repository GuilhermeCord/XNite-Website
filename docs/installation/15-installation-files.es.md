# Identificar los dos paquetes

**`.pext` instala X-Nite Profile System y `.pthm` el tema Fullscreen.** Necesitas ambos. No copies DLL ni carpetas manualmente. Si se incluye `SHA256SUMS.txt`, verifica los paquetes antes de instalarlos. La versión de las capturas es un ejemplo.
