<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

In Playnite Desktop, open **Menu > UniPlaySong Settings**. Music integration is optional; if used, follow the recommended setup in the next images.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Under **Quick Start > Profiles**, apply **Radio Mode (Random Game Music)** and enable **Spotify as the radio source**. Keep Spotify open and ready to play. This provides continuous music instead of changing tracks for each selected game. Also enable **Keep playing during games**.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Under **Playback > Startup**, choose **Play music in: Desktop + Fullscreen**. Keep the automatic-start and skip-first-selection options as shown.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

**Playback > Default Music** is separate. The screenshot selects the theme’s UPS audio source, but **Enable default music** is off. Leave it off for the recommended Spotify radio setup; this mode does not require the theme audio.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

Under **Pauses > Common Events**, keep **Pause on game launch** enabled and enable **Except Radio Mode (Radio Plays Through Games, PS4-Style)**. This exception lets Spotify radio continue during games. Save and test a game launch.

</div>
