# Ativar as logos dos jogos

<span class="xn-guide-optional">Opcional</span>

Abra `Extra Metadata Loader > Logos settings`. Ative **Enable logos** e revise tamanho e alinhamento conforme o print. O botão **Get API Key** abre o SteamGridDB: o próximo passo explica como obter a chave. O download automático de logos de jogos novos é opcional; deixe desativado se preferir decidir quando baixar.
