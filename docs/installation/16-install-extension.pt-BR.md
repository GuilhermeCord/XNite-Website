# Instalar o X-Nite Profile System

Abra **primeiro o `.pext`**. Confira se a confirmação mostra **X-Nite Profile System** e clique em **Sim / Yes**. Se solicitado, reinicie antes de instalar o tema. A extensão fornece os perfis e as integrações nativas do X-Nite.
