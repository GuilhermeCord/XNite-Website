<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

During initial setup, choose the libraries you use. These integrations import games from your accounts into Playnite.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Sign in to the selected libraries and finish importing. Use your own accounts; you do not need every store shown.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

In Desktop mode, open **Menu > Add-ons (F9)**.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Open **Browse > Generic** to find extensions that add features to Playnite.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

Install **Playnite Achievements**, **Extra Metadata Loader** and **Extra Metadata Fullscreen Mode Helper**. Also install **UniPlaySong** if you want the Spotify music setup. Restart when requested.

</div>

<div data-guide-note-start="5" data-guide-note-end="5" markdown="1">

Under **Browse > Metadata sources**, find providers for game information and images.

</div>

<div data-guide-note-start="6" data-guide-note-end="6" markdown="1">

Install the providers used by your libraries, including **SteamGridDB** for artwork. Their priority will be configured in the metadata step.

</div>

</div>
