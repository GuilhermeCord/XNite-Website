<div class="xn-tutorial__notes" tabindex="0" markdown="1">
Open `Menu > Add-ons (F9) > Browse`. Install **Playnite Achievements** for achievements and Gamescore. For logos and trailers, install **Extra Metadata Loader** and **Extra Metadata Fullscreen Mode Helper**. **UniPlaySong** is optional for game music. Add metadata providers for the stores you use, plus SteamGridDB for artwork. You do not need every provider in the screenshot. Restart Playnite when requested.

!!! success "Before continuing"
    The selected add-ons appear under Installed. Steam friends and audio controls are native X-Nite features.
