<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Apri **Menu > Impostazioni (F4) > Metadati**.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Controlla i fornitori per nome, descrizione, copertina e sfondo. Usa l’ordine mostrato come riferimento consigliato.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Apri l’elenco di un campo e ordina le fonti con le frecce. Quelle in alto hanno priorità; seleziona solo i fornitori che userai.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Apri **Menu > Componenti aggiuntivi (F9)** per configurare il fornitore di immagini.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

Apri **Impostazioni delle estensioni > Fonti dei metadati > SteamGridDB**.

</div>

<div data-guide-note-start="5" data-guide-note-end="5" markdown="1">

Scegli **Get API Key**, usa **Login via Steam**, poi **API > Create API Key**. Incolla la chiave SteamGridDB nel fornitore. Imposta **Cover: 1024×1024** e **Background: 3840×1240**. Mantieni privata la chiave; non è una chiave Steam Web API. Salva.

</div>
