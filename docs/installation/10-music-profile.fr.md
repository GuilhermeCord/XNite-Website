<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Dans Playnite Desktop, ouvrez **Menu > UniPlaySong Settings**. La musique est facultative ; si vous l’utilisez, suivez les réglages recommandés.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Dans **Quick Start > Profiles**, appliquez **Radio Mode (Random Game Music)** et activez **Spotify as the radio source**. Gardez Spotify ouvert et prêt. La musique reste continue au lieu de changer à chaque jeu sélectionné. Activez également **Keep playing during games**.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Dans **Playback > Startup**, choisissez **Play music in: Desktop + Fullscreen**. Conservez les options de démarrage automatique et de première sélection comme illustré.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

**Playback > Default Music** est indépendant. La capture sélectionne l’audio UPS du thème, mais **Enable default music** est désactivé. Laissez-le ainsi pour la radio Spotify ; ce mode ne nécessite pas l’audio du thème.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

Dans **Pauses > Common Events**, gardez **Pause on game launch** activé et activez **Except Radio Mode (Radio Plays Through Games, PS4-Style)**. Cette exception maintient la radio Spotify pendant les jeux. Enregistrez et testez un jeu.

</div>
