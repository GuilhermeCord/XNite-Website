# Choisir le profil musical

<span class="xn-guide-optional">Facultatif</span>

Ouvrez `Menu > UniPlaySong Settings > Quick Start`. Choisissez le preset souhaité. Le mode radio/Spotify montré **n’est pas obligatoire**. Pour une musique liée au jeu, choisissez le preset correspondant. Vous pouvez passer les quatre étapes UniPlaySong si vous ne souhaitez pas de musique dans les menus.
