<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

<span class="xn-guide-optional">Facultatif</span>

Ouvrez `Menu > UniPlaySong Settings > Quick Start`. Choisissez le preset souhaité. Le mode radio/Spotify montré **n’est pas obligatoire**. Pour une musique liée au jeu, choisissez le preset correspondant. Vous pouvez passer cette configuration UniPlaySong si vous ne souhaitez pas de musique dans les menus.

[Passer la configuration musicale →](14-download-xnite.md)

!!! success "Avant de continuer"
    Un preset est choisi, ou cette intégration facultative est ignorée.
</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

<span class="xn-guide-optional">Facultatif</span>

Dans UniPlaySong, ouvrez **Playback** et vérifiez le preset choisi. Activez seulement les options nécessaires. La lecture nécessite une source configurée ou des pistes disponibles pour les jeux ; le mode radio est facultatif.

!!! success "Avant de continuer"
    La lecture correspond au preset choisi.
</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

<span class="xn-guide-optional">Facultatif</span>

Dans `Playback > Default Music`, choisissez votre source. La musique locale nécessite des fichiers accessibles ; un mode Spotify nécessite Spotify ouvert et configuré. Utilisez vos fichiers et votre compte, pas les chemins de l’exemple. Testez un morceau avant Fullscreen.

!!! success "Avant de continuer"
    La source lit un morceau avant de passer en Fullscreen.
</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

<span class="xn-guide-optional">Facultatif</span>

Ouvrez `UniPlaySong > Pauses > Common Events`. Activez **Pause on game launch** pour arrêter la musique au lancement d’un jeu. Vérifiez l’exception radio si elle doit continuer. Les pauses liées au verrouillage, à l’inactivité et au focus sont personnelles. Enregistrez et testez.

!!! success "Avant de continuer"
    La musique s’arrête ou continue selon votre choix.
</div>
