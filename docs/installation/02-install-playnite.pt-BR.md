# Instalar o Playnite

Execute o instalador e escolha uma pasta permanente. O exemplo usa a instalação normal. O modo portátil também funciona, mas guarda os dados na própria pasta do Playnite. Abra o modo Desktop, conecte as bibliotecas que utiliza e aguarde a primeira importação.
