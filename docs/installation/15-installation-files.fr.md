# Identifier les deux paquets

**`.pext` installe X-Nite Profile System et `.pthm` le thème Fullscreen.** Les deux sont nécessaires. Ne copiez pas de DLL ou de dossiers manuellement. Vérifiez les paquets avec `SHA256SUMS.txt` s’il est fourni. La version affichée est un exemple.
