# Instalar X-Nite Profile System

Abre primero **`.pext`**. Confirma que aparece **X-Nite Profile System** y pulsa **Yes**. Reinicia si se solicita antes de instalar el tema. Esta extensión proporciona perfiles e integraciones nativas.
