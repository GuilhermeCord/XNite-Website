<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Apri il file **.pthm**. La finestra deve indicare **X-Nite — Xbox Experience for Playnite** e chiedere di installare un tema. Scegli **Sì / Yes**. Il pacchetto visivo completa l’estensione precedente.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Quando richiesto, scegli **Sì / Yes** per riavviare Playnite e caricare il tema installato. Attendi la fine dei download. L’installazione non lo seleziona come tema attivo; lo farai nel prossimo passaggio.
