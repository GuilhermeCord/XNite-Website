<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Open the **.pthm** file. The dialog should name **X-Nite — Xbox Experience for Playnite** and ask to install a theme. Choose **Yes**. This visual package complements the extension installed in the previous step.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

When requested, choose **Yes** to restart Playnite and load the installed theme. Wait for active downloads before confirming. Installation does not select the active theme; that is the next step.

</div>
