<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Dans Desktop, utilisez **Menu > Switch to Fullscreen Mode** ou appuyez sur **F11**.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Dans l’interface Fullscreen par défaut de Playnite, ouvrez le menu et choisissez **Settings / Paramètres**.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Ouvrez **Visuals**, où se choisit le thème Fullscreen.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Dans **Theme / Thème**, sélectionnez **X-Nite — Xbox Experience for Playnite**.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

Confirmez le redémarrage avec **Oui / Yes** pour appliquer le thème. Continuez ensuite pour choisir la langue initiale et créer votre profil.

</div>
