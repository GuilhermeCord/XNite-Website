# Conectar Playnite Achievements

Abre `Add-ons > Extension settings > Generic > Playnite Achievements`. Revisa **Sync & Updates**, activa `Platforms > Steam`, usa **Sign in** y confirma con **Check**. Completa una sincronización. Esta cuenta proporciona logros y Gamescore; los amigos usan por separado la cuenta del cliente Steam.
