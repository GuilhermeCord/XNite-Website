<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Escolha um avatar pronto ou selecione **+** para importar uma foto. A importação é opcional.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

No seletor de arquivos, escolha sua imagem e confirme. Use um arquivo do seu computador; a pasta do print é apenas um exemplo.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Ajuste o zoom e a posição para enquadrar o rosto na prévia circular. Escolha **Salvar** para manter o ajuste ou cancele para escolher outra foto.

</div>
