# Definire le pause della musica

<span class="xn-guide-optional">Facoltativo</span>

Apri `UniPlaySong > Pauses > Common Events`. Attiva **Pause on game launch** per fermare la musica all’avvio di un gioco. Controlla l’eccezione radio se deve continuare. Le pause per blocco, inattività e focus sono preferenze personali. Salva e prova.
