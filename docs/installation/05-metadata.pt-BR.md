<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Abra **Menu > Configurações (F4)** e entre em **Metadados**.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Confira os provedores habilitados para cada campo, como nome, descrição, capa e fundo. Use a ordem mostrada como referência recomendada para a biblioteca.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Abra a lista de um campo e use as setas para ordenar as fontes. As fontes no topo têm prioridade; marque apenas os provedores que pretende utilizar.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Agora abra **Menu > Complementos (F9)** para configurar o provedor de artes.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

Acesse **Configurações das extensões > Fontes de metadados > SteamGridDB**.

</div>

<div data-guide-note-start="5" data-guide-note-end="5" markdown="1">

Escolha **Get API Key**, entre com **Login via Steam** e abra **API > Create API Key**. Copie sua chave SteamGridDB para o provedor. Configure **Cover: 1024×1024** e **Background: 3840×1240**, como destacado. A chave é privada e não é uma chave da API Web da Steam. Salve.

</div>
