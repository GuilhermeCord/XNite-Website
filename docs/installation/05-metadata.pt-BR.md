# Configurar artes e metadados

Abra as configurações do **SteamGridDB Metadata Provider** e revise os tipos de arte. Depois, em `Configurações > Metadados`, ajuste a prioridade dos provedores para capas, fundos e demais campos. Prefira a loja oficial para informações e os provedores de arte para imagens, como nos exemplos. A chave SteamGridDB será criada no [passo 9](09-steamgriddb-api.md); volte aqui para colá-la se o provedor solicitar.
