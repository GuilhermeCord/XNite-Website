# Activar los logos de juegos

<span class="xn-guide-optional">Opcional</span>

Abre `Extra Metadata Loader > Logos settings`. Activa **Enable logos** y revisa tamaño y alineación. **Get API Key** abre SteamGridDB; el siguiente paso explica la clave. Las descargas automáticas de logos son opcionales.
