<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

En Playnite Desktop, abre **Menú > UniPlaySong Settings**. La música es opcional; si la utilizas, sigue el patrón recomendado.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

En **Quick Start > Profiles**, aplica **Radio Mode (Random Game Music)** y activa **Spotify as the radio source**. Mantén Spotify abierto y preparado. La música será continua en lugar de cambiar con cada juego seleccionado. Activa también **Keep playing during games**.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

En **Playback > Startup**, elige **Play music in: Desktop + Fullscreen**. Mantén las opciones de inicio automático y de omitir la primera selección como aparecen.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

**Playback > Default Music** es independiente. La captura selecciona el audio UPS del tema, pero **Enable default music** está desactivado. Déjalo así para la radio con Spotify; este modo no necesita el audio del tema.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

En **Pauses > Common Events**, mantén **Pause on game launch** activado y activa **Except Radio Mode (Radio Plays Through Games, PS4-Style)**. La excepción permite que Spotify siga durante los juegos. Guarda y prueba un juego.

</div>
