<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Abre el archivo **.pthm**. El diálogo debe indicar **X-Nite — Xbox Experience for Playnite** y preguntar por la instalación de un tema. Pulsa **Sí / Yes**. Este paquete visual complementa la extensión anterior.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Cuando se solicite, pulsa **Sí / Yes** para reiniciar Playnite y cargar el tema instalado. Espera a que finalicen las descargas. Instalarlo no lo selecciona como tema activo; lo haremos a continuación.
