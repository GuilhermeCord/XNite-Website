<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Obtén las herramientas del canal **download-extra** de la comunidad. El paquete contiene las utilidades de Extra Metadata Loader para los tráileres.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Extrae **FFmpeg** y conserva **yt-dlp.exe** en una carpeta permanente. La carpeta `bin` contiene **ffmpeg.exe** y **ffprobe.exe**. No selecciones el archivo comprimido.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Abre **Extra Metadata Loader > Videos settings**. Usa **Browse** para indicar **ffmpeg.exe**, **ffprobe.exe** e **yt-dlp.exe**. Las rutas mostradas son ejemplos. Activa **Enable video player** y desactiva **Autoplay videos** para iniciar los tráileres pausados. Guarda y prueba un vídeo.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

En **Logos settings**, activa **Enable logos**. Sigue **Get API Key > Login via Steam > API > Create API Key** y pega tu clave SteamGridDB. Puedes usar la misma del proveedor de imágenes; no es una clave Steam Web API. Guarda y prueba un logo.

</div>
