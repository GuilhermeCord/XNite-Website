<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Scarica gli strumenti dal canale della community **download-extra** mostrato. Il pacchetto contiene le utilità usate da Extra Metadata Loader per i trailer.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Estrai **FFmpeg** e conserva **yt-dlp.exe** in una cartella permanente. La cartella `bin` contiene **ffmpeg.exe** e **ffprobe.exe**. Non selezionare l’archivio compresso.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Apri **Extra Metadata Loader > Videos settings**. Usa **Browse** per scegliere **ffmpeg.exe**, **ffprobe.exe** e **yt-dlp.exe**. I percorsi mostrati sono esempi. Attiva **Enable video player** e disattiva **Autoplay videos** per avviare i trailer in pausa. Salva e prova un video.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

In **Logos settings**, attiva **Enable logos**. Segui **Get API Key > Login via Steam > API > Create API Key** e incolla la chiave SteamGridDB. Puoi usare la stessa del fornitore di immagini; non è una chiave Steam Web API. Salva e prova un logo.

</div>
