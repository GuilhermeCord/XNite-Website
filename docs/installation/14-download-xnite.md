# Download X-Nite

Get the theme and extension from the X-Nite community **downloads** channel shown below, or the project [Releases](https://github.com/GuilhermeCord/XNite-Distribution/releases) when available. Use matching versions and extract any archive first. The extras channel provides auxiliary tools, not replacements for the two X-Nite packages.
