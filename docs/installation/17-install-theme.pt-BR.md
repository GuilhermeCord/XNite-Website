<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Abra o arquivo **.pthm**. A confirmação deve identificar **X-Nite — Xbox Experience for Playnite** e perguntar pela instalação de um tema. Escolha **Sim / Yes**. Este pacote visual complementa a extensão do passo anterior.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Quando solicitado, escolha **Sim / Yes** para reiniciar o Playnite e carregar o tema instalado. Aguarde os downloads terminarem antes de confirmar. A instalação ainda não o seleciona como tema ativo; faremos isso no próximo passo.
