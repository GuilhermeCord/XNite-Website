# Instalar o tema Fullscreen

Abra o **`.pthm`**. Confira o nome **X-Nite — Xbox Experience for Playnite** na confirmação e selecione **Sim / Yes**. Isso instala o tema visual; ele não substitui a extensão Profile System do passo anterior.
