# Installer X-Nite Profile System

Ouvrez d’abord **`.pext`**. Vérifiez **X-Nite Profile System**, puis choisissez **Yes**. Redémarrez si demandé avant d’installer le thème. Cette extension fournit les profils et les intégrations natives.
