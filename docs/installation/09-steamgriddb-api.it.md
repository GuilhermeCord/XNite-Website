# Creare e applicare la chiave SteamGridDB

<span class="xn-guide-optional">Facoltativo</span>

1. Apri le [preferenze API di SteamGridDB](https://www.steamgriddb.com/profile/preferences/api) e usa **Login via Steam**.
2. In **API**, scegli **Create API Key** se necessario.
3. Incolla la chiave in **SteamGridDB API Key**, in `Extra Metadata Loader > Logos settings`.
4. Se richiesta da **SteamGridDB Metadata Provider**, usa la stessa chiave e salva.

È una chiave **SteamGridDB**, non Steam Web API. Mantienila privata e prova a scaricare un logo.
