# Review Playnite settings

Open `Menu > Settings (F4)`. Review `Appearance > Grid view`, `Layout` and `Advanced > Performance` using the screenshots. These are Desktop display preferences, not mandatory X-Nite values. Choose image quality appropriate for your display and hardware. Save your changes.
