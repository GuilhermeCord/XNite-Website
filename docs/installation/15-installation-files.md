<div class="xn-tutorial__notes" tabindex="0" markdown="1">
**`.pext` installs X-Nite Profile System. `.pthm` installs the Fullscreen theme.** Both are needed. Do not copy DLLs or extension folders manually. If supplied, verify the packages against `SHA256SUMS.txt`. The version in the filenames is an example; use the matching files from your download.

!!! success "Before continuing"
    Both the extension (.pext) and theme (.pthm) are present.
