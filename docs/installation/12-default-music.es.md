# Elegir la fuente musical

<span class="xn-guide-optional">Opcional</span>

En `Playback > Default Music`, elige tu fuente. La música local necesita archivos accesibles; un modo Spotify necesita Spotify abierto y configurado. Usa tus propios archivos y cuenta, no las rutas de ejemplo. Prueba una pista antes de pasar a Fullscreen.
