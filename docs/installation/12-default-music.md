# Choose the default music source

<span class="xn-guide-optional">Optional</span>

In `Playback > Default Music`, select your source. A local music pool needs accessible audio files; a Spotify-based mode needs Spotify running and configured in UniPlaySong. The paths in the screenshot belong to the example installation. Use your own files and account.
