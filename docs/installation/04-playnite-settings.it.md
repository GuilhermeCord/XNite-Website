# Verificare le impostazioni di Playnite

Apri `Menu > Settings (F4)`. Controlla `Appearance > Grid view`, `Layout` e `Advanced > Performance`. Sono preferenze Desktop, non requisiti del tema. Adatta la qualità delle immagini al computer e salva.
