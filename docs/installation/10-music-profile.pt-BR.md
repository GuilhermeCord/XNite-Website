# Escolher o perfil de música

<span class="xn-guide-optional">Opcional</span>

Abra `Menu > UniPlaySong Settings > Quick Start`. Escolha um preset de acordo com o comportamento desejado. O print mostra preferências pessoais de rádio/Spotify: elas **não são obrigatórias** para o X-Nite. Se quiser músicas associadas ao jogo selecionado, revise o preset correspondente. Se não quiser música nos menus, pule os quatro passos do UniPlaySong.

[Pular a configuração de música →](14-download-xnite.md)
