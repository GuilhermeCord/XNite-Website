# Verificare la riproduzione musicale

<span class="xn-guide-optional">Facoltativo</span>

In UniPlaySong, apri **Playback** e controlla il preset scelto. Attiva solo le opzioni necessarie. La riproduzione richiede una sorgente configurata o brani disponibili per i giochi; la modalità radio è facoltativa.
