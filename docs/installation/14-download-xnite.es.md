# Descargar X-Nite

Obtén tema y extensión del canal **downloads** de X-Nite mostrado o de [Releases](https://github.com/GuilhermeCord/XNite-Distribution/releases), cuando estén disponibles. Usa la misma versión y extrae el archivo comprimido. Los extras no sustituyen los dos paquetes.
