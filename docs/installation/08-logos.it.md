# Attivare i loghi dei giochi

<span class="xn-guide-optional">Facoltativo</span>

Apri `Extra Metadata Loader > Logos settings`. Abilita **Enable logos** e controlla dimensioni e allineamento. **Get API Key** apre SteamGridDB; il prossimo passo spiega come ottenere la chiave. I download automatici dei loghi sono facoltativi.
