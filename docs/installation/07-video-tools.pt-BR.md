<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Obtenha as ferramentas pelo canal **download-extra** da comunidade, mostrado na imagem. O pacote reúne os utilitários usados pelo Extra Metadata Loader para os trailers.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Extraia a pasta do **FFmpeg** e mantenha **yt-dlp.exe** em uma pasta permanente. Dentro de `bin` ficam **ffmpeg.exe** e **ffprobe.exe**. Não selecione o arquivo compactado.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Abra **Extra Metadata Loader > Videos settings**. Use **Browse** para indicar os seus arquivos **ffmpeg.exe**, **ffprobe.exe** e **yt-dlp.exe**. Os caminhos da imagem são exemplos. Mantenha **Enable video player** ativado e **Autoplay videos** desativado para iniciar os trailers pausados. Salve e teste um vídeo.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Em **Logos settings**, ative **Enable logos**. Siga **Get API Key > Login via Steam > API > Create API Key** e cole sua chave SteamGridDB no campo indicado. Pode ser a mesma do provedor de artes; ela não é uma chave da API Web da Steam. Salve e teste a logo de um jogo.

</div>
