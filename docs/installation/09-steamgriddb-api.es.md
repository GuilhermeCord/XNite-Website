# Crear y aplicar la clave SteamGridDB

<span class="xn-guide-optional">Opcional</span>

1. Abre las [preferencias API de SteamGridDB](https://www.steamgriddb.com/profile/preferences/api) y usa **Login via Steam**.
2. En **API**, pulsa **Create API Key** si no tienes clave.
3. Pégala en **SteamGridDB API Key**, en `Extra Metadata Loader > Logos settings`.
4. Si **SteamGridDB Metadata Provider** la solicita, utiliza la misma clave y guarda.

Es una clave **SteamGridDB**, no Steam Web API. Mantén tu clave privada y prueba a descargar un logo.
