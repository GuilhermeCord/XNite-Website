<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Obtain the tools from the **download-extra** community channel shown. The package contains the utilities used by Extra Metadata Loader for trailers.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Extract **FFmpeg** and keep **yt-dlp.exe** in a permanent folder. FFmpeg’s `bin` folder contains **ffmpeg.exe** and **ffprobe.exe**. Do not select the archive itself.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Open **Extra Metadata Loader > Videos settings**. Use **Browse** to select your **ffmpeg.exe**, **ffprobe.exe** and **yt-dlp.exe** files. The pictured paths are examples. Keep **Enable video player** on and **Autoplay videos** off to start trailers paused. Save and test a video.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Under **Logos settings**, enable **Enable logos**. Follow **Get API Key > Login via Steam > API > Create API Key**, then paste your SteamGridDB key. The artwork provider can use the same key; it is not a Steam Web API key. Save and test a game logo.

</div>
