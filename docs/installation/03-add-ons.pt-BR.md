# Instalar as integrações

Abra `Menu > Add-ons (F9) > Procurar`. Instale **Playnite Achievements** para conquistas e Gamescore. Para logos e trailers, instale **Extra Metadata Loader** e **Extra Metadata Fullscreen Mode Helper**. **UniPlaySong** é opcional para músicas dos jogos. Instale as fontes de metadados das lojas que utiliza e o SteamGridDB para artes. Não é preciso instalar todos os provedores do print. Reinicie quando solicitado.
