<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Téléchargez les outils dans le canal communautaire **download-extra** illustré. Le paquet contient les utilitaires utilisés par Extra Metadata Loader pour les bandes-annonces.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Extrayez **FFmpeg** et conservez **yt-dlp.exe** dans un dossier permanent. Le dossier `bin` contient **ffmpeg.exe** et **ffprobe.exe**. Ne sélectionnez pas l’archive.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Ouvrez **Extra Metadata Loader > Videos settings**. Utilisez **Browse** pour sélectionner **ffmpeg.exe**, **ffprobe.exe** et **yt-dlp.exe**. Les chemins illustrés sont des exemples. Activez **Enable video player** et désactivez **Autoplay videos** pour démarrer en pause. Enregistrez et testez une vidéo.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Dans **Logos settings**, activez **Enable logos**. Suivez **Get API Key > Login via Steam > API > Create API Key**, puis collez votre clé SteamGridDB. Le fournisseur d’images peut utiliser la même clé ; ce n’est pas une clé Steam Web API. Enregistrez et testez un logo.

</div>
