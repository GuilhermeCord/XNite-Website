# Télécharger X-Nite

Téléchargez thème et extension depuis le canal **downloads** X-Nite affiché ou depuis les [Releases](https://github.com/GuilhermeCord/XNite-Distribution/releases), lorsqu’ils sont disponibles. Utilisez la même version et extrayez l’archive. Les extras ne remplacent pas ces deux paquets.
