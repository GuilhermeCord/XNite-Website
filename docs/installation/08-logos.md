# Enable game logos

<span class="xn-guide-optional">Optional</span>

Open `Extra Metadata Loader > Logos settings`. Enable **Enable logos** and review size and alignment. **Get API Key** opens SteamGridDB; the next step explains how to obtain the key. Automatic downloads for newly added games are optional: leave them off if you prefer choosing when downloads run.
