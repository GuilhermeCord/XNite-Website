<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Lors de la configuration initiale, choisissez vos bibliothèques pour importer les jeux de vos comptes dans Playnite.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Connectez-vous aux bibliothèques choisies et terminez l’importation. Toutes les boutiques illustrées ne sont pas nécessaires.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Dans Desktop, ouvrez **Menu > Extensions (F9)**.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Ouvrez **Parcourir > Génériques** pour trouver les extensions de fonctionnalités.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

Installez **Playnite Achievements**, **Extra Metadata Loader** et **Extra Metadata Fullscreen Mode Helper**. Ajoutez **UniPlaySong** pour utiliser la musique Spotify. Redémarrez lorsque demandé.

</div>

<div data-guide-note-start="5" data-guide-note-end="5" markdown="1">

Dans **Parcourir > Sources de métadonnées**, recherchez les fournisseurs d’informations et d’images.

</div>

<div data-guide-note-start="6" data-guide-note-end="6" markdown="1">

Installez les fournisseurs de vos bibliothèques, dont **SteamGridDB** pour les images. Leur priorité sera configurée à l’étape des métadonnées.

</div>
