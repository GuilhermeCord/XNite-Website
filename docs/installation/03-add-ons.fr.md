# Installer les intégrations

Dans `Menu > Add-ons (F9) > Browse`, installez **Playnite Achievements** pour les succès et le Gamescore. **Extra Metadata Loader** et **Fullscreen Mode Helper** permettent logos et vidéos ; **UniPlaySong** est facultatif. Ajoutez les fournisseurs de vos boutiques et SteamGridDB pour les images. Tous les fournisseurs affichés ne sont pas nécessaires. Redémarrez si demandé. Amis et audio sont natifs dans X-Nite.
