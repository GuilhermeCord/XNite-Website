<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

In Desktop mode, open **Menu > Library > Download metadata**.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Choose the games and fields to download. Check before replacing artwork you have customized.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Review the selected providers. Use the sources installed and configured in the previous steps, then start the download.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Wait while Playnite downloads metadata and images. Duration depends on the number of games and providers.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

Switch to Fullscreen only after it finishes. If warned about background tasks, wait rather than canceling downloads.

</div>
