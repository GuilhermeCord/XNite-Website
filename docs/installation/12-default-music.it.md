# Scegliere la sorgente musicale

<span class="xn-guide-optional">Facoltativo</span>

In `Playback > Default Music`, scegli la sorgente. La musica locale richiede file accessibili; una modalità Spotify richiede Spotify aperto e configurato. Usa i tuoi file e il tuo account, non i percorsi dell’esempio. Prova un brano prima di Fullscreen.
