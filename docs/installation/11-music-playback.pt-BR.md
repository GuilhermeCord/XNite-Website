# Revisar a reprodução de música

<span class="xn-guide-optional">Opcional</span>

No UniPlaySong, abra **Playback** e revise o preset escolhido. Altere apenas as opções necessárias; não é preciso ativar rádio para ter músicas dos jogos. A reprodução depende de uma fonte configurada ou de faixas disponíveis para os seus jogos.
