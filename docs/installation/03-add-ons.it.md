# Installare le integrazioni

In `Menu > Add-ons (F9) > Browse`, installa **Playnite Achievements** per obiettivi e Gamescore. **Extra Metadata Loader** e **Fullscreen Mode Helper** permettono loghi e video; **UniPlaySong** è facoltativo. Aggiungi i fornitori delle tue piattaforme e SteamGridDB per le immagini. Non servono tutti i fornitori mostrati. Riavvia quando richiesto. Amici e audio sono nativi in X-Nite.
