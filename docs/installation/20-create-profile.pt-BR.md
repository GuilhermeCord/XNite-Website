<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Na tela **Quem está jogando hoje?**, selecione o cartão **+** para criar seu perfil. Os perfis do print são exemplos; a sua lista poderá ser diferente.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Escolha o idioma deste perfil. Ele pode ser diferente do idioma inicial e poderá ser alterado depois nas Configurações.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Digite o nome que será exibido no perfil e confirme pelo teclado virtual ou pelo teclado físico.
