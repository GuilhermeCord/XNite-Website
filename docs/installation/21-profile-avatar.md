<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Choose a preset avatar, or select **+** to import your own photo. Importing a photo is optional.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Select your image in the file picker and confirm. Use a file on your own computer; the screenshot shows an example folder.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Adjust the zoom and position so the face fits inside the circular preview. Choose **Save** to keep it, or cancel to choose another photo.

</div>
