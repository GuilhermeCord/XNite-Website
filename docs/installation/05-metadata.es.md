<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Abre **Menú > Ajustes (F4) > Metadatos**.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Revisa los proveedores de nombre, descripción, carátula y fondo. Usa el orden mostrado como referencia recomendada.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Abre la lista de un campo y ordena los proveedores con las flechas. Los primeros tienen prioridad; activa solo los que utilizarás.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Abre **Menú > Complementos (F9)** para configurar el proveedor de imágenes.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

Entra en **Configuración de extensiones > Fuentes de metadatos > SteamGridDB**.

</div>

<div data-guide-note-start="5" data-guide-note-end="5" markdown="1">

Pulsa **Get API Key**, entra con **Login via Steam** y abre **API > Create API Key**. Pega tu clave SteamGridDB en el proveedor. Configura **Cover: 1024×1024** y **Background: 3840×1240**. Mantén la clave privada; no es una clave Steam Web API. Guarda.

</div>
