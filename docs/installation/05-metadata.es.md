# Configurar imágenes y metadatos

Revisa los tipos de imagen de **SteamGridDB Metadata Provider**. En `Settings > Metadata`, prioriza tiendas oficiales para información y proveedores de arte para imágenes. La clave SteamGridDB se crea en el [paso 9](09-steamgriddb-api.md); vuelve aquí si el proveedor la solicita. Prueba primero con un juego.
