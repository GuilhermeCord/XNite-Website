# Configurer les images et métadonnées

Vérifiez les types d’images dans **SteamGridDB Metadata Provider**. Dans `Settings > Metadata`, privilégiez les boutiques officielles pour les informations et les fournisseurs d’images pour les visuels. La clé SteamGridDB sera créée à l’[étape 9](09-steamgriddb-api.md). Revenez ici si elle est demandée et testez sur un jeu.
