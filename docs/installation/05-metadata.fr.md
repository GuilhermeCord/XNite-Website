<div class="xn-tutorial__notes" tabindex="0" markdown="1">
Vérifiez les types d’images dans **SteamGridDB Metadata Provider**. Dans `Settings > Metadata`, privilégiez les boutiques officielles pour les informations et les fournisseurs d’images pour les visuels. La clé SteamGridDB sera créée à l’[étape 7](07-video-tools.md#image=5). Revenez ici si elle est demandée et testez sur un jeu.

!!! success "Avant de continuer"
    Testez les métadonnées sur un jeu avant d’actualiser toute la bibliothèque.
