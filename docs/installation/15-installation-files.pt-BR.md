# Identificar os dois pacotes

**O `.pext` instala o X-Nite Profile System. O `.pthm` instala o tema Fullscreen.** Os dois são necessários. Não copie DLLs ou pastas de extensão manualmente. Se fornecido, compare os pacotes com `SHA256SUMS.txt`. A versão nos nomes dos prints é um exemplo; use os arquivos correspondentes do seu download.
