# Create and apply the SteamGridDB key

<span class="xn-guide-optional">Optional</span>

1. Open [SteamGridDB API preferences](https://www.steamgriddb.com/profile/preferences/api) and select **Login via Steam**.
2. After signing in, open **API** and choose **Create API Key** if no key exists.
3. Copy it into **SteamGridDB API Key** in `Extra Metadata Loader > Logos settings`.
4. If **SteamGridDB Metadata Provider** also requests a key, paste the same key there and save.

This is a **SteamGridDB** key, not a Steam Web API key. You do not need a different key for each extension. Keep your key private; the screenshots hide the example key.
