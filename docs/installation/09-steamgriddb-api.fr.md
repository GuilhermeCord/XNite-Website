# Créer et utiliser la clé SteamGridDB

<span class="xn-guide-optional">Facultatif</span>

1. Ouvrez les [préférences API de SteamGridDB](https://www.steamgriddb.com/profile/preferences/api) et utilisez **Login via Steam**.
2. Dans **API**, choisissez **Create API Key** si nécessaire.
3. Collez la clé dans **SteamGridDB API Key**, sous `Extra Metadata Loader > Logos settings`.
4. Si **SteamGridDB Metadata Provider** la demande, utilisez la même clé et enregistrez.

C’est une clé **SteamGridDB**, pas une clé Steam Web API. Gardez-la privée et testez le téléchargement d’un logo.
