<div class="xn-tutorial__notes" tabindex="0" markdown="1">
Review artwork types in **SteamGridDB Metadata Provider**. In `Settings > Metadata`, set the provider order for each field. Prefer the official store for game information and artwork providers for images, as illustrated. The SteamGridDB key is created in [step 7](07-video-tools.md#image=5); return here to paste it if the provider requests it.

!!! success "Before continuing"
    Test a metadata download on one game before updating the whole library.
