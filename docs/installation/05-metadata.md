<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Open **Menu > Settings (F4) > Metadata**.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Review providers for each field, including name, description, cover and background. Use the illustrated order as the recommended reference.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Open a field’s provider list and use the arrows to reorder it. Sources at the top take priority; select only providers you intend to use.

</div>

<div data-guide-note-start="3" data-guide-note-end="3" markdown="1">

Open **Menu > Add-ons (F9)** to configure the artwork provider.

</div>

<div data-guide-note-start="4" data-guide-note-end="4" markdown="1">

Open **Extension settings > Metadata sources > SteamGridDB**.

</div>

<div data-guide-note-start="5" data-guide-note-end="5" markdown="1">

Choose **Get API Key**, use **Login via Steam**, then **API > Create API Key**. Paste your SteamGridDB key into the provider. Set **Cover: 1024×1024** and **Background: 3840×1240**, as highlighted. Keep the key private; it is not a Steam Web API key. Save.

</div>
