# Configure artwork and metadata

Review artwork types in **SteamGridDB Metadata Provider**. In `Settings > Metadata`, set the provider order for each field. Prefer the official store for game information and artwork providers for images, as illustrated. The SteamGridDB key is created in [step 9](09-steamgriddb-api.md); return here to paste it if the provider requests it.
