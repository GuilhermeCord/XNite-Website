<div class="xn-tutorial__notes" tabindex="0" markdown="1">
<div data-guide-note-start="0" data-guide-note-end="0" markdown="1">

Choose the main background and check its preview on the right. Use a preset, or select **+** to import an image or video.

</div>

<div data-guide-note-start="1" data-guide-note-end="1" markdown="1">

Select an image or video in the file picker. Importing media is optional; you can keep one of the included backgrounds.

</div>

<div data-guide-note-start="2" data-guide-note-end="2" markdown="1">

Check the imported background in the preview, focus the desired card and confirm your selection. You can change the background later.

</div>
