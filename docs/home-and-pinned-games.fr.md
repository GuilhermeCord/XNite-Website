# Accueil et jeux épinglés
Pour épingler un jeu, ouvrez ses détails, choisissez Plus d'options puis `Épingler à l'accueil`.

<img src="../../assets/screenshots/game-details.webp" alt="Détails du jeu avec illustration, bande-annonce et actions principales">

Pour réorganiser, appuyez sur Gauche depuis le premier jeu, ouvrez Organiser, choisissez un jeu et déplacez-le avec Gauche ou Droite. Confirmez ou appuyez sur B pour annuler.
