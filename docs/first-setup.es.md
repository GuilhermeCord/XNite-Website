# Configuracion inicial

## Integraciones

1. Revisa las integraciones recomendadas en la pantalla que aparece una sola vez.
2. Selecciona un elemento marcado como **Instalar ahora** y confirma **Install add-on?** en Playnite.
3. Reinicia Playnite cuando se solicite.
4. Completa la autenticacion o la configuracion del proveedor desde los ajustes de complementos del modo Desktop cuando sea necesario.
5. Selecciona **Continuar**. La lista sigue disponible en `Settings > Extensions > Integrations`.

La pantalla de integraciones no vuelve a aparecer despues de continuar. Una instalacion nueva abre el selector de perfiles en ingles de forma predeterminada.

## Primer perfil

1. Selecciona **Add** en la pantalla **Who is playing today?**.
2. Elige el idioma del perfil.
3. Introduce el nombre visible.
4. Elige un avatar o importa una foto.
5. Selecciona un color de acento.
6. Elige o importa el fondo principal.
7. Revisa la licencia y finaliza.

Cada perfil conserva su propio idioma, apariencia, favoritos, grupos y juegos fijados.
