# Controller e navigazione
| Comando | Azione |
|---|---|
| A / Invio | Seleziona o conferma |
| B / Esc | Torna indietro o annulla |
| D-pad | Sposta il focus |
| LB / RB | Cambia scheda dell'Hub |
| X | Modifica l'elemento importato selezionato |

B chiude prima il livello attivo, come un editor aperto dal profilo.
