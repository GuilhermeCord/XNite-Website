## Core components

Install both **X-Nite Profile System (.pext)** and the **X-Nite Fullscreen theme (.pthm)**. Add Playnite Achievements for achievements and Gamescore. Logos, trailer downloads and game music use their respective optional integrations.

!!! info "Steam & Audio"
    Steam friends and presence use the connected Steam client. Output devices, system volume and game audio use native X-Nite controls. No separate friends or audio add-on is required.
