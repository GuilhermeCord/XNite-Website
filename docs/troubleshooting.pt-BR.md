# Problemas comuns

## O tema não aparece

Confirme que o `.pthm` foi instalado, reinicie o Playnite e selecione X-Nite como tema Fullscreen.

## O perfil ou as imagens sumiram

Não reinstale removendo dados. Abra uma issue antes de alterar `ExtensionsData` e informe a versão anterior e a versão instalada.

## A área de trabalho aparece ao iniciar um jogo

Desative `Minimizar após iniciar um jogo` nas configurações Fullscreen do Playnite.

## O jogo abre, mas fica atrás do Playnite

Informe o nome do jogo, launcher, uso de anti-cheat e se o áudio do jogo começa. Inclua os logs do mesmo horário, removendo dados pessoais.

## Relatório útil

Inclua versão do Playnite, versão do X-Nite, Windows, resolução, controle usado, passos exatos e o trecho relevante dos logs.
