# Troubleshooting

## The theme is missing

Confirm that the `.pthm` was installed, restart Playnite and select X-Nite as the Fullscreen theme.

## The desktop appears while launching a game

Disable `Minimize after starting a game` in Playnite Fullscreen settings.

## The game opens behind Playnite

Report the game, launcher, anti-cheat use and whether game audio starts. Attach logs from the same time after removing personal data.

A useful report includes Playnite and X-Nite versions, Windows, resolution, controller and exact reproduction steps.
