# Premiere configuration

## Integrations

1. Consultez les integrations recommandees sur l'ecran affiche une seule fois.
2. Selectionnez un element marque **Installer maintenant**, puis confirmez **Install add-on?** dans Playnite.
3. Redemarrez Playnite lorsque cela est demande.
4. Si necessaire, terminez l'authentification ou la configuration du fournisseur dans les parametres d'extensions du mode Desktop.
5. Selectionnez **Continuer**. La liste reste disponible dans `Settings > Extensions > Integrations`.

L'ecran des integrations ne reapparait pas apres avoir continue. Une nouvelle installation ouvre par defaut le selecteur de profils en anglais.

## Premier profil

1. Selectionnez **Add** sur l'ecran **Who is playing today?**.
2. Choisissez la langue du profil.
3. Saisissez le nom affiche.
4. Choisissez un avatar ou importez une photo.
5. Selectionnez une couleur d'accentuation.
6. Choisissez ou importez l'arriere-plan principal.
7. Consultez la licence et terminez la configuration.

Chaque profil conserve sa langue, son apparence, ses favoris, ses groupes et ses jeux epingles.
