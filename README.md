# X-Nite Website

Public presentation and multilingual installation guide for X-Nite.

This repository contains only the MkDocs website: documentation, screenshots, styles and templates. It does not contain the Playnite extension source, DLLs, packages, user caches or development logs.

Website: https://GuilhermeCord.github.io/XNite-Website/

## Local preview

```sh
pip install -r requirements.txt
mkdocs serve
```

## Publication

GitHub Actions builds the website with `mkdocs build --strict` and deploys it to GitHub Pages. Set Settings > Pages > Source to GitHub Actions.
