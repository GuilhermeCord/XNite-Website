# X-Nite for Playnite

A controller-first Playnite Fullscreen experience with personal profiles, customization, game groups, pinned games and achievement integration.

## Installation

Obtain both packages through the paid distribution channel.

1. Install **X-Nite Profile System** (`.pext`).
2. Restart Playnite.
3. Install **X-Nite - Xbox Experience for Playnite** (`.pthm`).
4. Open `Settings > Appearance > Fullscreen theme` and select X-Nite.
5. Enter Fullscreen mode and create the first profile.

[Open the complete multilingual guide](https://GuilhermeCord.github.io/XNite-Website/)
